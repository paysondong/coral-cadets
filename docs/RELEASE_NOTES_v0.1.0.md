# v0.1.0 — Original Version

This release preserves the original CoralCadets prototype as the public starting point of the project.

The purpose of v0.1.0 is not to present a finished redesign. It creates a visible baseline so later releases can show how the gameplay, visual language, mathematical systems, and environmental storytelling improve over time.

## Public-repository cleanup

- Removed local `.env` files from the public package.
- Added `.env.example` with placeholders only.
- Removed macOS `.DS_Store` metadata.
- Added a project README and public roadmap.
- No gameplay code was intentionally redesigned for this release.
