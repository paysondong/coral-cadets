The second release of CoralCadets, built directly on the original nine-level coral-themed match-3 game.

## What's new

- Redesigned deep-ocean home screen, streamlined menus, and Score / Moves / Goals / Bloom HUD.
- Invalid swaps no longer consume moves, goals trigger an immediate win, and adjacent tiles can be swapped by tapping.
- Boards with no available moves automatically reshuffle with Current Shift.
- New Pulse, φ Bloom, Symmetry Wave, and Fibonacci Flow match and cascade effects.
- Reef Bloom rewards strong play with bonus points and growing background coral.
- A shared responsive portrait layout for desktop and mobile.
- Direct access to the game, with sign-in and registration kept optional.
- Refreshed Reef Score, Ocean Cards, About, and Support panels.
- Complete image, font, and audio assets included.

The original version remains available as v0.1.0. GitHub Pages is not enabled as part of this release.

## Validation

Full TypeScript checking and the production build pass. The build retains non-blocking lint and tooling warnings. Release preparation also synchronizes dependency installation and fixes TypeScript compatibility for iterator expansion and Phaser audio volume control.
