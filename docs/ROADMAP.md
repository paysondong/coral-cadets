# CoralCadets Roadmap

CoralCadets is intentionally evolving in small, visible steps.

## v0.1.0 — Original
Preserve the original coral-themed match-3 game as the project's baseline.

## v0.2.0 — Visual Redesign
- New CoralCadets identity
- Indigo / coral / violet / pearl / warm-gold art direction
- Cleaner game HUD
- Better motion, underwater atmosphere and responsive layout
- English / 中文 / 日本語 foundation

## v0.3.0 — Mathematical Play
Mathematics becomes part of the game feel rather than a lesson:
- 4-match Pulse
- 5-match φ Bloom
- cross/T patterns as symmetry effects
- 3 → 5 → 8 Fibonacci combo rhythms
- golden-angle and recursive visual motion

## v0.4.0 — Living Reef
- The reef visibly grows as the player succeeds
- More fish and coral appear through play
- Lightweight Reef Cards introduce real conservation facts without interrupting the game

## v1.0.0 — Portfolio Edition
A polished, open web release with playtesting notes, design documentation, automated web deployment, and a clearly documented code/media license.
